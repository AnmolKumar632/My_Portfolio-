## Design Tips

- **Aspect Ratio:** Generate images in 16:9 or 4:3 ratio to fit portfolio card containers
- **Color Scheme:** Adjust color keywords to match portfolio accent colors (purple, violet, indigo)
- **Resolution:** 8k for best quality, will be downscaled automatically
- **Format:** PNG with transparency support preferred

## How to Add Images

1. Generate image using the prompt above
2. Save to `public/projects/` folder with the specified filename
3. The portfolio will automatically display the image instead of the SVG animation
4. If image fails to load, the SVG animation fallback will show
